# NutriTrack AI Module

## Overview
This folder contains the Machine Learning core for NutriTrack, replacing rule-based BMI recommendations.

## Structure
- `data/` → Training data in JSON
- `models/` → Saved ML model & label encoder
- `scripts/` → Train & predict scripts
- `output/` → Last prediction results
- `environment/requirements.txt` → Python libraries

## Setup
1. Create Python virtual environment
2. Install dependencies:
   ```bash
   pip install -r environment/requirements.txt
